# Output Contract

## Analysis Mode

Use this structure when the user wants diagnosis without file edits:

### Current Judgment
- one to three stable conclusions

### Evidence Basis
- list the direct evidence
- list any inference separately

### Next Teaching Move
- one main goal
- one to two correction points
- one drill path
- optional resource-backed practice pack when catalogs are available

### Persistence Decision
- should update `MEMORY.md`
- should update `USER.md`
- should wait for more evidence

## Execution Mode

Use this structure when the user wants you to update files:

### Updated Points
- what changed in `MEMORY.md`
- what changed in `USER.md`

### Why It Changed
- cite the evidence class: direct evidence, inference, or cohort pattern

### Next Micro-Loop
- target
- drill path
- success signal

### Recommended Practice Pack
Use this section when listening, word, and picture-book catalogs are available:
- target bridge: weak words that have matching resources
- listening picks: unit, level, configured question count, linked question count, matched target words
- quick-word picks: word, unit, audio availability, meaning, example sentence
- picture-book picks: title, vocabulary size, duration, matched target words

## Teaching Loop Template

Use this compact loop when producing the next lesson:
- Goal: one sentence
- Warm-up: one familiar success item
- Correction: one phoneme, one word set, or one sentence frame
- Transfer: one short sentence pattern
- Exit check: one measurable criterion
