# Evolution Rules

## 1. Evidence Threshold

Promote an observation into long-term memory only when it is:
- repeated
- cross-task
- cross-day
- or teaching-critical

Single-event noise stays out of persistent files.

## 2. Source Boundary

Use these labels internally when reasoning:
- `direct evidence`: explicit score, item, date, transcript, behavior
- `inference`: a cautious interpretation of repeated evidence
- `cohort pattern`: pattern from multiple learners, not a single child
- `conflict`: new evidence that does not yet justify overwrite

## 3. File Assignment

`MEMORY.md`
- strategy
- stable teaching moves
- stage decomposition
- cohort-level implications

`USER.md`
- individual portrait
- strengths
- weak points
- pacing and feedback constraints

## 4. Update Style

Write like slides, not diaries:
- short headers
- flat bullets
- no raw dump
- no duplicated points with slightly different wording

Use this sequence:
1. conclusion
2. evidence
3. action

## 5. Conflict Handling

If old and new signals disagree:
- prefer newer direct evidence over older inference
- prefer repeated evidence over isolated evidence
- if still unclear, do not overwrite; report the conflict and what evidence is missing

## 6. Teaching Translation

Every meaningful diagnosis should become one concrete next move:
- target
- drill sequence
- feedback rule
- success threshold
